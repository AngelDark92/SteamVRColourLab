# Portable + VR dashboard validation — 2026-09-25

Version: 0.2.0. This source directory has no Git metadata; SOURCE_SHA256.txt
records the final source files. The ZIP has a separate SHA-256 sidecar.

## Implemented

- A Windows x64 folder/ZIP bundles CPython, Tcl/Tk, OpenVR, GLFW and Pillow.
- All 19 Settings fields are reachable with pointer controls inside a SteamVR
  dashboard, together with presets, cycling, recenter, save/load, reports and exit.
- Numeric and text editors live inside the dashboard. Reports use the current
  VR settings without applying an unfinished desktop draft.
- System overlay input accepts whichever controller/hand pointer SteamVR
  supplies. Native bottom-left mouse coordinates are mapped into the top-left UI.
- Procedural shaders, float eye targets and linear OpenVR scene submission are
  unchanged. Dashboard pixels do not enter the source-precision test image.

## Remaining runtime validation

No live SteamVR session was launched, no driver was deployed, and no headset
was controlled. Still to verify on the user's connected headset:

1. Launch the portable EXE; Colour Lab dashboard opens and has upright text.
2. Point at Source near the top and Recenter near the bottom. Each must hover
   and click in place; check either controller and either available hand pointer.
3. Change each page, enter a fractional RGB value and a note, save/load settings,
   and save a report while remaining in VR.
4. Close the SteamVR dashboard with its normal system control. Confirm both
   eyes show the float test panel; reopen Colour Lab and switch A/B modes.
5. Confirm focus transitions and recentering behave properly while streaming.

Raw skeleton data without SteamVR dashboard pointer/select actions is not a
supported input source. Successful mocked events cannot establish hand-pinch
mapping, overlay visibility, raw image acceptance, compositor texture acceptance,
real-time frame rate, or preservation of 10-bit values through the stream/panel.

## Reproduce

```powershell
.venv/Scripts/python.exe -m unittest discover -v
.venv/Scripts/python.exe app.py --self-test
powershell -NoProfile -ExecutionPolicy Bypass -File tools/Build-Portable.ps1
dist/SteamVRColourLab/SteamVRColourLab.exe --self-test
dist/SteamVRColourLab/SteamVRColourLab.exe --desktop --frames 8
```
